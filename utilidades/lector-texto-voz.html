[Utilidad] General

Lector de
texto a voz.

Pega un texto y escúchalo en voz alta. Usa las voces que ya vienen instaladas en tu propio dispositivo, así que no hay ninguna API de por medio ni el texto sale de tu navegador. Puedes ajustar la velocidad y el tono.

Texto

0 caracteres

Voz y ajustes

Tus datos no se envían a ningún sitio. Esta herramienta no tiene servidor: todo ocurre dentro de tu navegador. Es gratis, no hay registro y no se guarda nada.

De dónde salen las voces

De tu propio dispositivo. Windows, macOS, Android e iOS traen voces instaladas, y esta página simplemente le pide al navegador que las use mediante la API de síntesis de voz que ya lleva incorporada. No hay ningún servicio de pago detrás ni el texto viaja a ninguna parte.

La consecuencia es que las voces disponibles dependen de tu equipo. En dos ordenadores distintos verás listas distintas. Si quieres más voces en español, se instalan desde los ajustes de idioma de tu sistema operativo, no desde aquí.

Para qué se usa

  • Revisar un texto escuchándolo: los errores de redacción se detectan mucho mejor de oído.
  • Escuchar un artículo largo mientras haces otra cosa.
  • Comprobar cómo suena un guion antes de grabarlo.
  • Accesibilidad, para quien prefiere escuchar antes que leer en pantalla.

Preguntas frecuentes

¿Necesito instalar algo?

No. Usa las voces que ya trae tu sistema operativo a través del navegador.

¿Puedo descargar el audio en MP3?

No. La API de síntesis del navegador reproduce el sonido pero no permite guardarlo en un archivo. Para eso harían falta un servicio externo y un servidor, que es justo lo que esta herramienta evita.

¿Por qué veo pocas voces en español?

Porque dependen de tu dispositivo, no de esta página. Puedes añadir más desde los ajustes de idioma y voz de tu sistema operativo.

¿Se envía el texto a algún servidor?

No. Todo el proceso ocurre en tu navegador, con las voces instaladas en tu equipo.
